DATABASE SETUP INSTRUCTIONS
============================

PostgreSQL:
  - You need to set your own PostgreSQL password during installation
  - Database name: crime_intelligence_db
  - Update the password in backend/.env file

Steps:
  1. Install PostgreSQL (remember your password!)
  2. Create database: CREATE DATABASE crime_intelligence_db;
  3. Import data: psql -U postgres -d crime_intelligence_db -f database/crime_intelligence_db_backup.sql
  4. Copy backend/.env.example to backend/.env
  5. Edit backend/.env and add your PostgreSQL password


IMPORTANT NOTES
===============

- DO NOT share your .env file (contains sensitive passwords)
- The .env.example file is safe to share (no real passwords)
- Each team member should create their own .env file
- Keep passwords secure!
